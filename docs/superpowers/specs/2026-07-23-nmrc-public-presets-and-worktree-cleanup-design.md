# N-MRC 正式入口合并与实验工作区整理设计

日期：2026-07-23

## 目标

将已经完成变量实验的 N-MRC 机制整理为三个稳定、可复现的公开入口，同时保留既有实验数据，并清除确认无用的实验分支临时内容。

## 正式方案

公开运行入口只保留：

1. `n-mrc`
   - 默认方案。
   - 保持当前四级网络侧判定、换路和 FastCNP/cooldown 行为不变。
   - 不因新增预设改变现有命令行的默认值或实验语义。

2. `n-mrc-fixed0.5`
   - 对应原实验方案 `n-mrc4` 的实际实现。
   - 默认绝对拥塞阈值为 `0.5`，默认相对质量差阈值为 `0.25`。
   - 满足该预设的既有判定条件后，将换路和 FastCNP 作为配对动作。

3. `n-mrc-delta`
   - 仅依据当前路径与候选路径的相对质量差进行决策。
   - 默认 `delta=0.25`。
   - 换路和 FastCNP 保持配对。

`n-mrc1/2/4/5/6/7` 和 `n-mrc-allcool-rr-reset` 不作为公开可运行名称保留。历史数据中的旧名称不重命名，以保证实验来源可追溯。

## 文档

根目录 `README.md` 增加 N-MRC 方案说明，明确默认方案和两个可选预设，并简要记录以下后续研究方向，但本次不实现：

- 换路与冷却分离：绝对分数超过 `0.5` 时允许网络侧换路；只有进一步超过独立冷却阈值时，FastCNP 才携带 cooldown 指示，促使端侧冷却该 EV。
- 分段相对阈值：绝对分数 `0.5` 以下和以上分别采用不同的 `delta`，使轻度相对失衡和明确拥塞采用不同灵敏度。

实验目录 README 同步记录三个正式入口、默认参数、动作语义和旧名称对应关系。

## 实验数据保留

将相关工作树中尚未汇总到主工作区的实验输出合并到主工作区 `experiments/n-mrc/output/`，包括：

- 原 `n-mrc` 实验的热图、FCT 表格和原始输出；
- 原 `n-mrc4` 实验的热图、FCT 表格和原始输出；
- 路径累计字节、路径使用率、CV/方差时间线等新微观分析数据和图片。

同名文件处理遵循：

- 内容相同：只保留一份；
- 内容不同：不静默覆盖，保留来源目录或增加明确来源后缀；
- 实验目录名称保持原样，不把历史 `n-mrc4` 数据伪装成新跑的 `n-mrc-fixed0.5` 数据。

`experiments/*/output*/` 已由 `.gitignore` 忽略。合并后再次用 `git check-ignore` 和 `git status` 验证实验数据不会进入提交。

## 实现与测试

从实验工作树选择性提取正式预设所需的最小改动：

- 命令行入口与参数校验；
- 预设配置解析；
- 交换机质量比较和决策逻辑；
- FastCNP/cooldown 所需的现有元数据；
- 针对三个公开入口及阈值行为的单元/接口测试。

不整体复制实验工作树，不合入与三个正式入口无关的临时重构。

测试至少覆盖：

- 原 `n-mrc` 默认配置在合并前后不变；
- 两个新增入口可解析且默认参数正确；
- 非法参数、重复参数和不适用方案上的参数被拒绝；
- `fixed0.5` 与 `delta` 的阈值边界行为；
- 编译和现有 N-MRC/SGLB 回归测试。

## 清理边界

完成代码、文档、数据汇总和验证后：

- 删除确认由本轮变量实验产生、且已被正式测试或文档取代的重复临时脚本；
- 清理由 Git 管理的、已完成且内容已合并的 N-MRC 实验工作树和对应临时分支；
- 保留所有实验输出和仍有独立用途的绘图/分析脚本；
- 不删除其他主题的工作树或分支；
- 不清理主工作树中无法确认归属的现有未提交修改；
- 删除分支前核对其独有提交和未提交文件，任何未被合并或归档的内容都先保留。

最终交付应让主分支的跟踪文件保持干净；被忽略的实验数据可以继续存在于输出目录中。
