# MRC cold-QP flow-size evidence design

## Objective

Validate the user's lifecycle theory: a new per-QP MRC instance behaves like
stateless RR while feedback cannot affect later DATA selections, then becomes
useful as a flow survives enough RTTs and 64-EV rotations. Compare the same
flows with the continuously updated SGLB fabric view and isolate the cost of
independent per-QP learning under pre-existing congestion.

## Controlled topology and protocol

- 256 hosts: four Leaves with 64 hosts each and 64 Spines.
- One 400 Gbit/s plane, 64 physical paths and 64 active MRC EVs per QP.
- 4 KiB DATA MTU, so one nominal EV rotation is 256 KiB.
- MRC uses canonical `skip_token`; RR is its stateless selector.
- SGLB uses real 256-byte high-priority GCN packets, dToR profiles, 15 us
  remote cadence, exact-min24 candidate fallback, and shuffled RR.
- Use paired seeds 13, 29, and 47. Traffic files are identical across MRC, RR,
  and SGLB within each seed and condition; conclusions must survive all three
  seeds rather than relying on one favorable path hash.

## Traffic and pressure

Foreground traffic is an open-loop WebSearch-like mixture. Short flows
(6/33/133 KiB) contribute 10% offered load and long flows (3.3/6.5 MiB)
contribute 56%. Measurement probes at 256/512/667 KiB and 1/1.3/2 MiB fill
the transition region and contribute about 4.3%, keeping total foreground near
70%. Arrivals are Poisson over 50--1150 us; only flows
starting in the 250--950 us steady window are measured, so every measured QP
starts after fabric pressure has formed.

Four network conditions use the same measured foreground traffic:

1. `healthy`: 64 equal-capacity paths and no fixed background.
2. `fixed_hotspot`: 16 paths carry persistent 390 Gbit/s bidirectional
   fixed-link background for the complete run.
3. `ecmp_mixed`: persistent large background flows use per-flow ECMP, while
   measured WebSearch flows use the selected RR, MRC, or SGLB scheme. Only
   measured flows enter FCT summaries; background-flow placement and bytes
   are retained for imbalance diagnostics.
4. `slow_uplink`: 16 uplinks per Leaf run at half capacity, selected
   deterministically per seed, while the foreground mixture maintains load.

The fixed-hotspot condition is the primary mechanism result. The ECMP-mixed
condition tests persistent utilization imbalance generated by real large
flows. The slow-uplink condition checks that the conclusion is not specific to
synthetic packet sources. The simulator's generic `mixed_lb_traffic` switch is
excluded because it overrides every tenth connection regardless of cohort and
would route some measured short flows through ECMP.

## Metrics

All FCT comparisons are same-flow ratios before geometric aggregation:

- `MRC/RR` isolates endpoint feedback learning because encoding and rotation
  are otherwise identical.
- `MRC/SGLB` compares cold per-QP feedback with a warmed fabric view.
- `condition/healthy` measures the pressure-induced degradation of each
  scheme.
- Average and p99 FCT are reported separately; no maximum is labelled p99.

MRC mechanism metrics are:

- `nominal_rotations = new_data_selections / 64`;
- actual complete-EV sweeps from `full_sweeps`, labelled separately;
- EV coverage `unique_active_evs / 64`;
- actionable-flow fraction, where feedback changed path state and at least one
  later original DATA selection occurred in the same QP.
- first effective-feedback delay relative to QP start, compared with measured
  no-load RTT;
- pre-feedback DATA selections and post-feedback original DATA selections;
- per-QP evidence that a new QP starts without inheriting another QP's MRC
  path state despite background pressure already being present.

## Falsifiable theory checks

The report may claim support only when the data satisfy the corresponding
mechanism observation:

1. **Short-flow RR equivalence:** flows with zero post-feedback original DATA
   selections have MRC/RR near one within the observed sampling spread, and no
   improvement is attributed to their own feedback.
2. **One-RTT startup delay:** the first accepted quality feedback occurs no
   earlier than the causal data/ACK return path, and useful control requires at
   least one later original DATA selection.
3. **One-rotation control delay:** at 4 KiB MTU, 64 nominal choices equal
   256 KiB. The report distinguishes nominal cursor rotations from actual
   full-EV coverage and does not assume that transmitting 256 KiB guarantees
   actionable feedback.
4. **Long-lifecycle benefit:** actionable fraction and rotations rise with
   flow size; in at least the primary persistent-imbalance condition, MRC/RR
   improves for medium-long or long flows relative to the short-flow region.
5. **Independent-QP exploration:** newly started MRC QPs under warmed pressure
   still show cold feedback delay and risky pre-feedback choices, whereas SGLB
   can use its existing fabric view. MRC/SGLB is therefore worse for short
   flows and approaches SGLB as flow lifetime grows, subject to measured noise.

If a check fails, the report states that the experiment does not support that
part of the theory and diagnoses the observed boundary instead of selecting a
different subset post hoc.

## Visual and report

The primary static figure has four aligned flow-size panels: pressure
degradation by scheme, paired MRC/RR and MRC/SGLB ratios, nominal versus actual
rotations/coverage, and actionable-flow fraction. A robustness figure compares
fixed hotspot, ECMP-mixed background, and slow uplinks. Exact plot data,
paired-flow rows, a manifest with hashes, raw logs, PNG/PDF figures, and a
technical Markdown report are retained together.

## Interpretation boundary

Actionable feedback is necessary but not sufficient for FCT improvement.
Short-flow differences with zero actionable feedback arise from workload-level
queueing externalities, recovery behavior, or sampling variation, not from the
flow learning a path. MRC/SGLB is a full-scheme comparison and is not presented
as a pure cross-QP-sharing ablation.
